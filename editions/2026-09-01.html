August took the corpus international.

At the end of July the Axiom Foundation covered US federal and state law and UK council schemes. A month later three more countries are in, and the shape of the work did not change to accommodate them.

The corpus · 28 August 2026
9,069 source documents · 94,366 provisions · 4,155 RuleSpec encodings
Every figure is live on the coverage page — check them against this email whenever you like.

corpus
What got encoded

At launch on 28 July we published just over 3,000 encodings, so the corpus grew by roughly a third in a month. Three countries arrived alongside that growth.

Canada came first, with the Canada Workers Benefit as administered by the CRA. Belgium followed with a worker personal-income-tax pipeline, and Denmark after that — which meant teaching the pipeline to read Retsinformation’s LexDania format, since Danish law does not publish itself the way US law does.

The US picture stays uneven and we would rather show that than average it away. Colorado leads the states at 1,010 encodings, North Carolina follows at 489 and California at 389, while a dozen states sit in single digits. Breadth of source documents came first; encoding depth follows program by program.

engine
What moved toward certification

The validation dashboard became the cutover process this month, with four measured gates a package has to clear rather than a judgment call someone makes. Alongside it we added guards against silent failure — a coverage-cliff check and a catalog smoke test — so a package that quietly stops covering what it claims gets caught by the system rather than by a user.

Parity triage also got sharper. Known-difference classes are now separated from real gaps, which matters because the two look identical in a diff and mean opposite things.

api
One build

The API learned to answer questions about time. A new temporal read path exposes rule version history and an as_of parameter, so you can ask what a rule computed on a date in the past rather than only what it computes today. For anyone reconstructing a determination — an appeal, an audit, a researcher checking a paper — that difference is the whole job.

The same release added a variables catalog and variable-addressed calculation, so a caller can ask for one value by name instead of pulling a whole household result apart. The compiled runtime also gained a fallback to a vendored WASM engine, which means the rules run in more places without a service call.

ask
Tell us which program to encode next

The state table on the coverage page shows where we are thin, and we would rather that list be shaped by people who work in these programs than by what happens to be easiest to reach. If you work on benefits administration in a state sitting in single digits, reply and name the program that would matter most.
